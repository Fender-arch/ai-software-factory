# 10 — Принципы проекта

> Перевод. Канон: [`docs/10-Project-Principles.md`](../10-Project-Principles.md)

| Поле | Значение |
|------|----------|
| Status | Accepted |
| Version | 0.2 |
| Updated | 2026-09-05 |
| Owner | ASF Core |

1. **Процесс важнее оргструктуры** — роли существуют потому, что существуют стадии.
2. **Orchestrator намеренно «глупый»** — логика workflow в коде, не в промптах.
3. **Один Coordinator, много режимов** — выделять процессы позже, если понадобится.
4. **Память важнее чата** — долговечный KG сильнее истории диалога агентов.
5. **Человек контролирует** — гейты на ТЗ и жёстких решениях.
6. **KISS со стержнем** — сохраняем граф и режимы; GraphDB/event-sourcing откладываем, пока не доказана необходимость.
7. **Заморозка MVP** — новые идеи → фильтр → бэклог Future.
8. **Документы исполнимы** — схемы, промпты, решения ограничивают систему.
9. **Cursor — инструмент** — не центр оркестрации.
10. **Сначала простые типы продуктов** — website, bot, service, automation, native mobile.
