# 10 — Project Principles

| Field | Value |
|-------|-------|
| Status | Accepted |
| Version | 0.1 |
| Updated | 2026-07-30 |
| Owner | ASF Core |

1. **Process over org chart** — roles exist because stages exist.
2. **Orchestrator is dumb (on purpose)** — workflow logic is code, not prompts.
3. **One Coordinator, many modes** — extract processes later if needed.
4. **Memory over chat** — durable KG beats agent dialogue history.
5. **Human in control** — gates on TZ and hard decisions.
6. **KISS with spine** — keep the graph and modes; drop GraphDB/event-sourcing until proven necessary.
7. **MVP freeze** — new ideas → filter → Future backlog.
8. **Docs are executable** — schemas, prompts, decisions constrain the system.
9. **Cursor is a tool** — not the center of orchestration.
10. **Simple product types first** — website, bot, service, automation.
