# Product type: website

## Typical MVP

- Marketing / brochure site or simple landing
- Contact form or CTA
- Responsive layout
- Optional CMS-lite (static content in repo)
- If TZ `design_direction` is loud/3D: first-viewport motion, copy hooks, optional lightweight 3D/WebGL hero on the same landing (not a game or 3D editor)

## Discovery checklist

- [ ] Audience and primary CTA
- [ ] Current process / why a site
- [ ] Pages / sections
- [ ] Public identity (name/brand shown to visitors)
- [ ] Offer catalog (services + copy; portfolio if claimed)
- [ ] Visitor CTA (public contact, lead fields, destination)
- [ ] Brand assets availability
- [ ] Design references (URLs/screens) and what to reuse
- [ ] Design direction (calm/laconic vs modern motion vs loud 3D — impacts estimate)
- [ ] Promotion in v1 (SEO, ads, Metrika) vs out of development scope
- [ ] Legal: 152-FZ / personal data, cookies, industry rules (impacts estimate)
- [ ] Form destinations (email, CRM, none)
- [ ] Languages and mobile
- [ ] Hosting expectation
- [ ] Out of scope (no payments unless approved)
- [ ] Timeline (required vs expected)
- [ ] Budget range or request for a quote
- [ ] Contact details and preferred channel
- [ ] Acceptance: how the owner will check v1

## Out of scope for this template

Multi-tenant SaaS, complex auth, payments (escalate or narrow). Multi-scene cinematic 3D / game-engine sites (escalate; a single WebGL hero is in scope when TZ asks).
