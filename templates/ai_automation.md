# Product type: ai_automation

## Typical MVP

- Trigger (webhook, schedule, or Telegram)
- LLM or rules step
- Side effect (email, sheet, ticket, notify)
- Logging of runs

## Discovery checklist

- [ ] Trigger
- [ ] Inputs / outputs and side effect
- [ ] Human approval / guardrails
- [ ] Failure handling
- [ ] Cost / rate limits
- [ ] Data sensitivity
- [ ] Legal: 152-FZ if personal data goes into the model (impacts estimate)
- [ ] What is logged after a run
- [ ] Timeline and budget
- [ ] Contact details and preferred channel
- [ ] Acceptance

## Out of scope for this template

Autonomous multi-agent enterprises, unrestricted tool use without HITL.
