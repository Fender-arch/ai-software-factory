# Product type: telegram_bot

## Typical MVP

- Bot commands / conversational flow
- Persistence of user state
- Admin or owner notifications optional

## Discovery checklist

- [ ] Primary user jobs
- [ ] Bot chat vs Mini App landing
- [ ] Commands vs free-text vs voice
- [ ] Public identity (name/brand shown to visitors)
- [ ] Offer catalog (services + copy; portfolio if claimed)
- [ ] Visitor CTA (public contact, lead fields, destination)
- [ ] Brand assets availability
- [ ] Design references and what to reuse (Mini App / public bot)
- [ ] Design direction (calm vs motion vs 3D — impacts estimate)
- [ ] Promotion if the bot/Mini App is a public landing (SEO/ads/analytics)
- [ ] Legal: 152-FZ / personal data (impacts estimate)
- [ ] Auth / who can use the bot
- [ ] What is stored about the user
- [ ] External systems to call
- [ ] Languages
- [ ] Out of scope
- [ ] Timeline and budget
- [ ] Contact details and preferred channel
- [ ] Acceptance / operator after launch

## Out of scope for this template

Payments unless explicitly approved. A Mini App landing (services, portfolio, contact/lead) is in scope as `telegram_bot` + `telegram_miniapp`. Crafted motion and a lightweight 3D/WebGL hero are in scope when TZ `design_direction` asks — still one Mini App, not a game engine.
