# Product type: telegram_bot

## Typical MVP

- Bot commands / conversational flow
- Persistence of user state
- Admin or owner notifications optional

## Discovery checklist

- [ ] Primary user jobs
- [ ] Commands vs free-text
- [ ] Auth / who can use the bot
- [ ] External systems to call
- [ ] Voice input needed?
- [ ] Languages

## Out of scope for this template

Telegram Mini Apps with heavy frontend, payments unless explicitly approved.
