# TZ graph pictograms

Subset of [Lucide](https://lucide.dev/) (`lucide-static@0.511.0`, ISC).

Used as circular badges on owner-console graph nodes:

- **product hub** — website / telegram_bot / rest_service / ai_automation / mobile_native
- **stages** — Discovery FSM
- **topics** — TZ outline sections (`discovery/tz_outline.py`), including product-specific ones (pages, bot chat, API resources, AI trigger)

Refresh: `python scripts/download_tz_icons.py`

Attribution: see `LICENSE-Lucide.txt`. Mapping: `map.json`.
